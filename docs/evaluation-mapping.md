# Evaluation Criteria Mapping: SnapAssist

> **Challenge:** Qualcomm Snapdragon® AI Lab Build & Present Challenge 2026  
> **Project:** SnapAssist — Private On-Device AI Workspace  
> **Tagline:** *"Your files. Your AI. Your device."*  

This document explicitly maps the implemented features, codebase components, and demonstration procedures of SnapAssist to the four official evaluation criteria of the competition.

---

## 1. Criterion 1: Technical Implementation

### What Was Implemented
- **Modular AI Architecture:** Engineered an abstract provider layer (`AIProvider`) decoupling model execution from high-level workspace logic. Implemented `QualcommAIHubProvider`, `LocalONNXProvider`, and `LocalLLMProvider`.
- **Qualcomm Snapdragon NPU Targeting:** Integrated ONNX Runtime configured to prioritize the Qualcomm Neural Network (`QNNExecutionProvider`) for the Hexagon™ NPU (up to 45 TOPS platform rating on Snapdragon X Elite) and DirectML (`DmlExecutionProvider`), with automated fallback to `CPUExecutionProvider` for universal cross-platform testing.
- **Truthful Hardware Telemetry:** Implemented `HardwareDetector` which queries system architecture, logical cores, unified memory, available ONNX execution providers, and Qualcomm AI Hub SDK availability. The application strictly refuses to fake NPU execution.
- **On-Device RAG Pipeline:** Developed an end-to-end vector pipeline including PyMuPDF document extraction, semantic overlapping sliding chunker, 384-dimensional dense vector embeddings, and in-memory NumPy SIMD cosine similarity vector search (`LocalVectorStore`).
- **Local Vision & OCR:** Created a local layout analyzer using OpenCV and PIL that detects text regions, classifies UI types, and runs on-device OCR without external cloud vision APIs.
- **Automated Benchmarking Suite:** Built `scripts/benchmark.py` measuring cold-start latency, warm latency, token throughput, document parsing throughput, and memory consumption.
- **Test Suite:** Built automated unit and integration tests passing cleanly.

### Relevant Code & Components
- `backend/ai/provider_base.py`: Abstract Base Class for inference backends.
- `backend/ai/qualcomm_aihub_provider.py`: Qualcomm AI Hub model integration targeting Snapdragon X Elite CRD.
- `backend/ai/local_onnx_provider.py`: ONNX Runtime session management with QNN EP auto-detection.
- `backend/ai/hardware_detector.py`: Verified hardware and runtime provider detection.
- `backend/retrieval/vector_store.py`: Vectorized SIMD matrix cosine similarity search.
- `backend/ingestion/document_parser.py`: PyMuPDF, python-docx, and image parsing.
- `backend/ai/ocr_engine.py`: Local OpenCV/PIL computer vision layout and OCR engine.
- `scripts/benchmark.py`: Reproducible empirical performance measurement.
- `tests/`: Automated tests covering ingestion, chunking, retrieval, providers, API, and security.

### What Should Be Demonstrated During Judging
1. Open the **Performance Dashboard** to show live hardware detection: processor architecture, active execution provider (`QNNExecutionProvider` / `DirectML` / `CPUExecutionProvider`), and status.
2. Run `python scripts/benchmark.py` in the terminal to generate and inspect fresh benchmark metrics (`benchmarks/latest_benchmark_results.json`).
3. Run `python -m pytest tests/` to show all automated unit and integration tests passing cleanly.

## 2. Criterion 2: Application Use Case & Innovation

### What Was Implemented
- **Private Knowledge Management:** Solves the acute privacy crisis of cloud AI assistants by confining documents, embeddings, and chat prompts to local device memory.
- **Grounded Citations (Minimizing Hallucinations):** Every response generated by SnapAssist includes explicit page citations `[Doc: filename, Page: X]` and allows users to click to inspect the underlying source snippet.
- **Multi-Format Document Repository:** Full drag-and-drop support for PDF, DOCX, TXT, Markdown, and screenshot images with automated layout detection.
- **One-Click Document Summarization:** Generates structured TL;DR summaries, key points, action items (with owner and due dates), and timeline milestones entirely on-device.
- **Multimodal Image Intelligence:** Allows users to upload UI screenshots or slides and ask questions about the visual text content without sending images to cloud APIs.
- **Semantic Vector Search:** Natural language search returning matching passages with percentage match scores and sub-5ms retrieval.

### Relevant Code & Components
- `backend/api/routes_documents.py`: Document ingestion, chunking, and metadata storage.
- `backend/api/routes_chat.py`: Grounded RAG chat endpoint with citation anchors.
- `backend/api/routes_summarize.py`: Structured summarization (TL;DR, key takeaways, action items).
- `backend/api/routes_image.py`: Multimodal image layout classification and visual Q&A.
- `frontend/src/pages/ChatWorkspace.tsx`: Interactive chat UI with citation drawer.
- `frontend/src/pages/ImageAnalysis.tsx`: Screenshot analysis with interactive Q&A.

### What Should Be Demonstrated During Judging
1. Drag and drop the sample Snapdragon technical whitepaper into the **Documents** repository. Show instant parsing.
2. In **AI Workspace**, ask: *"Summarize this document and identify the three most important action items."* Point out the precise page citation badges.
3. Click a citation badge to reveal the verified underlying source passage in the drawer.
4. Upload a screenshot in **Image Analysis** and ask questions about the text contained in the screenshot.

## 3. Criterion 3: Deployment & Accessibility

### What Was Implemented
- **Windows-First Optimization:** Designed specifically for Windows 11 on Snapdragon Copilot+ PCs (HP OmniBook X, HP EliteBook Ultra).
- **One-Command Setup & Run Scripts:** Created `setup.ps1` (automates Python/Node dependency verification and installation) and `run.ps1` (launches backend and frontend with a single command).
- **Zero Cloud Infrastructure:** Requires no cloud subscriptions, no external database instances, no Docker daemons, and no API keys.
- **100% Offline Capability:** Full core document search, ingestion, summarization, and chat operate with network interfaces completely severed.
- **Modern Responsive Desktop UI:** Engineered with React 19, TypeScript, Vite, and Tailwind CSS v4, featuring Snapdragon Crimson brand styling, high contrast, and accessible typography.

### Relevant Code & Components
- `setup.ps1`: Automated environment setup for Windows.
- `run.ps1`: One-command dual-server launcher.
- `frontend/vite.config.ts`: Vite bundler configuration with API reverse proxy.
- `frontend/src/App.tsx`: Responsive navigation shell.
- `requirements.txt` & `frontend/package.json`: Locked, audited dependencies.

### What Should Be Demonstrated During Judging
1. Show execution of `.\setup.ps1` or `.\run.ps1` launching the workspace in seconds.
2. Sever network connectivity (toggle Airplane Mode or disconnect Wi-Fi) and demonstrate that all document ingestion, search, and AI queries function seamlessly.
3. Highlight the clean, responsive desktop UI with Snapdragon branding.
